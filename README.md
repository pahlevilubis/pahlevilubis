# Pahlevi Lubis

System Analyst working on IBM i (AS400) for banking since 2007: ATM switching, middleware, core banking and ISO 8583 integrations. Outside work, I build small Android and Windows apps for everyday problems.

**Portfolio:** [pahlevilubis.github.io](https://pahlevilubis.github.io) (Bahasa Indonesia) or [the English version](https://pahlevilubis.github.io/?lang=en)

## What I work with

- **IBM i:** RPG, RPGLE free-form, SQLRPGLE, CLLE/CLP, COBOL, Db2 for i, PASE
- **Integration:** ISO 8583, REST APIs and JSON from RPGLE, H2H, PGP file exchange
- **Payments and security:** Euronet ITM, EMV, PCI-DSS
- **Side projects:** Android and Windows apps, built and released with GitHub Actions

## Tools I built on IBM i

- **HTTPTOOL:** Postman-style API testing from a 5250 screen, with curl import, Axis or curl PASE engines, and automatic tokens. RPGLE and CL programs call the same configs through HTTPSEND.
- **PGP File Exchange:** encrypts and decrypts partner files with GnuPG in PASE, verifies SHA512 checksums before decryption, and tracks every file in a 5250 monitor.

Both were built for real banking projects, so the source stays private. The portfolio has interactive simulations of their screens.
